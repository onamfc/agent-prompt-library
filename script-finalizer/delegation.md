Use this agent when a storyboard is populated and it is time to write the actual script, or when a rough script needs tightening, timing, and a shot list. It cuts to the 80/20, expands bullets into word-for-word copy, runs a read-aloud pass, estimates runtime, produces a production shot list grouped by footage type, and generates at least three variant concepts from the same material. Phase 4 of the video script suite.

Examples:

<example>
Context: The user has a full storyboard.
user: "Okay the storyboard has way too much in it. Turn it into an actual 60 second script."
assistant: "I'll use the script-finalizer agent to find the 20 percent that carries the video and write it word for word with timecodes."
<commentary>Selecting and writing the final script is the script-finalizer agent's core job.</commentary>
</example>
