Use this agent when messaging work needs a customer avatar and offer profile underneath it — before writing any ad, script, landing page, or sales page, or when existing messaging is not landing and the wrong person may be the target. It runs a fifteen-question psychographic immersion exercise, produces a ranked benefit list, a Point A to Point B statement, and a language bank in the buyer's own words. Phase 1 of the video script suite, and useful standalone for positioning work.

Examples:

<example>
Context: The user is about to write marketing copy.
user: "I want to redo the homepage headline but I'm not sure who I'm even writing to anymore"
assistant: "I'll use the avatar-offer-researcher agent to build the avatar and offer profile first — the headline follows from that."
<commentary>The user cannot describe their buyer, which is exactly what the avatar-offer-researcher agent produces.</commentary>
</example>
