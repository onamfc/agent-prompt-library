Use this agent to audit marketing claims and attach proof to them, or force them to change. It inventories every claim in a script, landing page, or sales page, assigns each a validation path (testimonials, case studies, third-party research, or mutually agreed upon facts), and returns a verdict table of VALIDATED, SOFTEN, CUT, or BLOCKED. When run inside the product's own repository it also verifies capability claims against the actual implementation. Use it before producing any asset that promises results, speed, price advantage, or superiority, and whenever an offer is being dismissed as too good to be true.

Examples:

<example>
Context: The user has a script full of promises.
user: "Before we shoot this, can you check whether any of these claims are going to get us in trouble?"
assistant: "I'll use the claim-validator agent to audit every claim and tell you which ones have proof, which need softening, and which have to be cut."
<commentary>Auditing claims for supportability is the claim-validator agent's core job.</commentary>
</example>

<example>

assistant: "Let me launch the claim-validator agent — running inside this repository it can check capability claims against the implementation."
<commentary>Verifying marketing claims against shipped code is a claim-validator agent capability.</commentary>
</example>
