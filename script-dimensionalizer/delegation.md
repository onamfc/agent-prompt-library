Use this agent when a script has the right structure but not enough weight behind it — the offer is explained but buying does not feel like a no-brainer. It selectively applies seven techniques: naming the mechanism, value stacks, comparison stacks, objection prevention, humor, B-roll and stock footage, and motion graphics. It is deliberately selective, stating which techniques it skipped and why. Also use it standalone for mechanism naming, value stack construction, competitive comparison framing, or objection handling. Phase 3 of the video script suite.
