Use this agent when a video needs its opening — the first five to ten seconds that earn the rest of the runtime. It generates ten to twenty hooks with paired visual treatments across seventeen attention-getting concepts, recommends a top three, and proposes test pairs. Use it standalone when the user asks specifically for hooks, openers, scroll-stoppers, or a cold open, or as component 1 of the video script suite.

Examples:

Context: The user has a script but a weak opening.
user: "The body of this ad is fine but the first line is boring. Give me options."
assistant: "I'll use the hook-architect agent to generate a batch of hooks with visual treatments and flag the strongest three."
<commentary>The user needs openings specifically, so go straight to the hook-architect agent rather than the full pipeline.</commentary>
